# 💰 Planos Gratuitos para Deploy do Backend

## 🚂 Railway (Recomendado) ⭐

### Plano Gratuito:
- ✅ **$5 de crédito grátis por mês**
- ✅ **Sem cold start** (serviço sempre ativo)
- ✅ **Deploy automático** via GitHub
- ✅ **HTTPS automático**
- ✅ **Logs em tempo real**
- ✅ **Domínio gratuito** (`.up.railway.app`)

### Quanto isso cobre?
- **Projeto pequeno/médio:** Geralmente fica dentro do crédito grátis
- **Uso típico:** ~$2-4 por mês (dentro do limite)
- **Se passar:** Você é avisado e pode escolher pagar ou otimizar

### Limites:
- **Memória:** 512MB por serviço (suficiente para a maioria)
- **CPU:** Compartilhado (suficiente para uso normal)
- **Bandwidth:** Incluído no crédito

**Conclusão:** Para a maioria dos projetos, o plano gratuito é suficiente! 🎉

## 🎨 Render (Alternativa)

### Plano Gratuito:
- ✅ **Totalmente gratuito** (sem limite de crédito)
- ✅ **Deploy automático** via GitHub
- ✅ **HTTPS automático**
- ✅ **Logs disponíveis**

### ⚠️ Limitações Importantes:
- **Cold Start:** Serviço "dorme" após 15 minutos de inatividade
- **Primeira requisição:** Pode demorar ~30 segundos para "acordar"
- **Timeout:** Requisições longas podem ser canceladas

### Quando usar Render:
- Projeto pessoal/teste
- Baixo tráfego
- Não se importa com cold start

## 💡 Dica de Economia

Para economizar créditos no Railway:
1. **Desligue serviços** quando não estiver usando (no dashboard)
2. **Otimize o código** (menos memória = menos custo)
3. **Use variáveis de ambiente** corretamente (evita rebuilds desnecessários)
